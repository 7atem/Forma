# Forma exercise illustrations

Original two-phase 3D still renders generated with the built-in `image_gen` tool for this project. No competitor artwork or exercise video was copied. Eight unchanged 1536×1024 PNGs are shared by Android and Apple project resources.

- Files: `res/drawable-nodpi/exercise_*.png`
- Exact generation prompts: `catalog/exercise-art-prompts.json` at repository root.
- SHA-256/byte manifest: `catalog/exercise-art-manifest.json`.
- Named variations, bilingual editorial cues and references: `catalog/exercise-guides.json`.
- Review and product limitations: `docs/EXERCISE_DEMOS_AND_UX.md`.

Visually reviewed examples, not motion capture or qualified personal-form assessment. Expert review of each pose/cue remains a public-release gate. Original files remain unchanged; Android's viewer isolates a phase at display time. Start is physically left and movement right, including RTL presentation.
